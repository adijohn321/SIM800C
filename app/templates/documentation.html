Overview

SIM800C SMS Manager is a self-hosted service that sends, receives and stores SMS through a SIM800C GSM module. It exposes a JSON REST API and a web UI backed by the same API, so anything you can do in the UI you can automate.

  • Ingest — messages are pulled from the SIM card on a poll interval and stored in SQLite (data/messages.db).
  • Send — POST /api/sms/send writes an outbound record and pushes the SMS through the modem.
  • Discover — the serial port is auto-detected; no need to know which COM port the modem landed on.
  • Inspect — signal, operator, IMEI and SIM state come from /api/modem/status.
Interactive OpenAPI documentation (try-it-out requests) is served at /docs and the raw schema at /openapi.json.

Quick start

cd C:\SIM800C
.\.venv\Scripts\Activate.ps1
python run.py

The server starts on http://localhost:8000 (host/port come from HOST / PORT). With SIM800C_PORT=auto the modem is located automatically at startup and on every reconnect. 

# health check — no auth required
curl http://localhost:8000/api/health

Authentication

Auth is optional. When API_KEY is set in .env, every /api/* request must carry it in the X-API-Key header; otherwise requests are accepted anonymously. 

curl -H "X-API-Key: your-secret" http://localhost:8000/api/sms

A missing or wrong key returns 401 {"detail": "Invalid or missing API key"}. The web UI prompts once and stores the key in localStorage.

Port auto-detection

Set SIM800C_PORT=auto (the default) and the service finds the port the SIM800C is plugged into itself:

  1. Signature scan — every serial port is scored from its USB identity (SIMCom/SIM800 strings, known USB-UART bridges: CP210x, CH340/CH341, FT232, PL2303). An unambiguous match is used immediately.
  2. AT probe — otherwise up to 6 candidate ports are opened at SIM800C_BAUDRATE and sent AT; the port answering OK wins.
  3. Re-detect — with an auto port, detection runs again on every connect, so replugging the modem on another port is handled.

Current configuration: SIM800C_PORT={{ configured_port }} {% if auto_port %}auto-detect enabled{% else %}manual port{% endif %}

Trigger detection manually with POST /api/modem/detect or inspect scored candidates with GET /api/modem/ports. Set a concrete value (e.g. COM3, /dev/ttyUSB0) to bypass detection entirely.

API reference

Base URL: http://localhost:8000. All bodies are JSON.

MethodPathPurpose
GET/api/healthLiveness check (no auth)
GET/api/modem/statusConnection, signal, operator, IMEI, SIM state
POST/api/modem/connectOpen the serial port (auto-detects when port is auto)
POST/api/modem/disconnectClose the serial port
GET/api/modem/portsList serial ports with detection score/reason
POST/api/modem/detectAuto-detect the SIM800C port now
POST/api/sms/sendSend an SMS {"phone","message"}
GET/api/smsList stored messages (filters: direction, phone, status, limit, offset)
GET/api/sms/{id}Fetch one message
DELETE/api/sms/{id}Delete a message (and on the SIM if indexed)
POST/api/sms/syncPull the SIM inbox into SQLite now
POST/api/sms/injectSimulate inbound SMS (mock mode only)
GET/api/statsCounts: total/inbound/outbound/unread/failed

Integration examples

Send an SMS

curl -X POST http://localhost:8000/api/sms/send \
  -H "Content-Type: application/json" \
  -H "X-API-Key: your-secret" \
  -d '{"phone": "+15551234567", "message": "Hello from SIM800C"}'
Invoke-RestMethod -Method POST -Uri http://localhost:8000/api/sms/send `
  -ContentType "application/json" `
  -Headers @{ "X-API-Key" = "your-secret" } `
  -Body '{"phone":"+15551234567","message":"Hello from SIM800C"}'
const res = await fetch("http://localhost:8000/api/sms/send", {
  method: "POST",
  headers: { "Content-Type": "application/json", "X-API-Key": "your-secret" },
  body: JSON.stringify({ phone: "+15551234567", message: "Hello from SIM800C" }),
});
const message = await res.json();   // { id, status: "sent", ... }

List messages

curl "http://localhost:8000/api/sms?direction=inbound&limit=20"

Detect the modem port

curl -X POST http://localhost:8000/api/modem/detect -H "X-API-Key: your-secret"

# → {"device":"COM5","description":"SIMCom SIM800C","hwid":"VID_1A86&PID_7523",
#    "method":"signature","score":120,"reason":"SIM800/SIMCom identifier found, WCH CH340 USB-UART bridge"}

Modem status

curl http://localhost:8000/api/modem/status -H "X-API-Key: your-secret"

# → {"connected":true,"mock":false,"port":"COM5","signal_rssi":21,
#    "network_registered":true,"operator":"Vodafone","imei":"867...","sim_ready":true}

Message model

FieldTypeDescription
idintDatabase id
directionstringinbound or outbound
phonestringSender (inbound) or recipient (outbound), E.164 recommended
bodystringMessage text (max 1600 chars)
statusstringunread/read (in), sending/sent/failed (out)
modem_indexint?Storage index on the SIM card (inbound only)
created_at / updated_atstringUTC ISO-8601 timestamps
errorstring?Failure reason for failed messages

Errors

Errors are returned as JSON with a detail string:

{"detail": "Modem is not connected"}
StatusMeaning
401Missing/invalid X-API-Key
404Message not found, or no SIM800C detected (/api/modem/detect)
422Validation error (missing/invalid fields)
502Modem reported an error (send/sync failed)
503Modem not connected / port cannot be opened

Receiving SMS

Inbound SMS is imported automatically every {{ poll_seconds }} s (SIM800C_POLL_SECONDS, 0 disables). To react to new messages from your own service, poll the API: 

GET /api/sms?direction=inbound&status=unread

Keep a cursor on id (messages are returned newest-first) and mark processing by deleting or re-querying. You can also force an import any time with POST /api/sms/sync. The service auto-reconnects the modem when it drops (SIM800C_AUTO_RECONNECT=true).

Mock mode

With SIM800C_MOCK=true no hardware is touched: a simulated modem connects instantly, three sample messages are seeded, sending succeeds after a short delay, and the Inject inbound SMS tool appears in the UI (POST /api/sms/inject). Use it for development and demos.

All settings come from .env (see .env.example).

SIM800C_TIMEOUT5AT response timeout in seconds
SIM800C_MOCKtrueRun without hardware

SIM800C_AUTO_RECONNECTtrueReconnect from the poller when the modem drops
HOST / PORT0.0.0.0 / 8000HTTP bind address

After changing .env, restart python run.py for the new values to take effect.
